# Getting Started with Ghrew

## Overview

This guide walks a new visitor from opening the Ghrew sandbox to sending a first message in a public channel.

## Guidance

- Open the sandbox and continue with GitHub using your own account
- Try the local preview with ?preview=1 before signing in
- Join a public channel and post a test message to confirm delivery

## Notes

This guide is part of the Ghrew documentation set under `docs/guides/`. Keep it updated when the related behaviour changes.
