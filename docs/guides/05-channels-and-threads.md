# Channels and Threads Guide

## Overview

This guide explains how shared channels, comments, and threads are organised in Ghrew.

## Guidance

- Use public channels for team-wide discussion
- Keep follow-ups inside threads to reduce noise
- Refresh public channels if a message does not appear yet

## Notes

This guide is part of the Ghrew documentation set under `docs/guides/`. Keep it updated when the related behaviour changes.
