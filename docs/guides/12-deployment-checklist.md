# Pre-Deployment Checklist

## Overview

This guide is a final checklist before publishing a new Ghrew deployment.

## Guidance

- Verify sign-in works for a second participant
- Test one public and one private channel end to end
- Confirm no secrets are committed to the repository

## Notes

This guide is part of the Ghrew documentation set under `docs/guides/`. Keep it updated when the related behaviour changes.
