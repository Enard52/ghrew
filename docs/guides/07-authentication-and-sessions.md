# Authentication and Sessions

## Overview

This guide describes how sign-in, tokens, and logout behave in Ghrew.

## Guidance

- Sign in with your own GitHub account, never a shared token
- Tokens stay in the browser tab session storage
- Logging out clears credentials and remote caches

## Notes

This guide is part of the Ghrew documentation set under `docs/guides/`. Keep it updated when the related behaviour changes.
