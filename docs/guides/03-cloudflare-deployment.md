# Cloudflare Deployment Checklist

## Overview

This guide summarises the recommended Cloudflare deployment path that packages the client and backend together.

## Guidance

- Choose a random SETUP_TOKEN of at least 32 characters
- Open /create/ on the new site and follow the guided setup
- Verify the ghrew-chat and ghrew-vault repositories were created

## Notes

This guide is part of the Ghrew documentation set under `docs/guides/`. Keep it updated when the related behaviour changes.
