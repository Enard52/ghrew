# Workspace Setup Guide

## Overview

This guide explains how a GitHub organization maps to a Ghrew workspace and what to prepare before creating one.

## Guidance

- Confirm organization membership for every participant
- Set organization base permissions to None before creating the vault
- Decide which channels are public and which must stay private

## Notes

This guide is part of the Ghrew documentation set under `docs/guides/`. Keep it updated when the related behaviour changes.
